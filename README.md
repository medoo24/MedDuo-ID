## ✨ المميزات الرئيسية

### 1. موقع البودكاست (`podcast-site/`)
- **حوار مصري كوميدي واقعي:** حوار مشوق بين د. طارق وخريج/طالب الطب عاطف مليء بمواقف المشرحة وامتحانات الأوسبي.
- **تثبيت أرقام الامتحان:** تكرار الأرقام الذهبية (14، 16، 17، 18، 21 بالكوع والرسغ والركبة، درزات الجمجمة، فروق الحوض، جداول الأسنان، وغيرها).
- **تحرير مباشر وحفظ محلي:** دبل كليك لتعديل أي فقرة أو اسم، أزرار إضافة وحذف، مع حفظ كل شيء تلقائياً في `localStorage`.
- **أوضاع مخصصة:** وضع ليلي/نهاري، وضع قراءة صافي بدون فقاعات، فلترة المتكلمين، وسرعات تمرير هادئة ومريحة.

### 2. موقع السلايدات (`slides-site/`)
- **لغة أكاديمية إنجليزية:** تغطية 8 حلقات كاملة بجداول مقارنة وحلول قضايا جنائية وأسئلة مراجعة.
- **تصدير حقيقي لـ PowerPoint:** زر `PowerPoint (.pptx)` يولد ملف XML أصلي يفتح على مايكروسوفت باوربوينت بدون أخطاء.
- **تحميل فوري لـ PDF:** زر `Download PDF` ينزل ملف العرض كـ PDF مباشر بضغطة زر.
- **دعم الميديا المتعددة والوضعيات:** إضافة صور ثابتة، صور GIF متحركة، ومقاطع فيديو قصيرة، مع اختيار موقع الميديا (فوق، يمين، يسار، تحت).
- **أرشيف واستنساخ السلايدات (Stash):** استنساخ أي سلايد ولصقها في أي حلقة أخرى بضغطة زر.
- **شاشة كاملة بضغطة زر (F):** اضغط `F` للدخول في وضع العرض والخروج منه بسلاسة.

## ⚙️ خطوات تفعيل GitHub Pages (خلال دقيقة واحدة)
1. ادخل على إعدادات المستودع: **Settings**.
2. من القائمة الجانبية اضغط على **Pages**.
3. تحت قسم **Build and deployment**:
   - Source: اختر **Deploy from a branch**.
   - Branch: اختر **main** والمسار **/(root)**.
   - اضغط **Save**.
4. خلال دقيقة سيصبح موقعك متاحاً للعالم على:
   `https://medoo24.github.io/MedDuo-ID/`
